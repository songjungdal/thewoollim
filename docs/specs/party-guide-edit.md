## 1. 작업 목적

1. **"참가 신청 방법"과 "필수 확인 사항"을 파티마다 관리자가 고칠 수 있게** 한다. 지금은 종류별 고정 문구(`app/lib/partyGuides.ts`)라 고칠 수 없다.
2. **진행 안내(Party Timeline)를 자유 형식으로 쓸 수 있게** 한다. 지금은 단계마다 번호 동그라미("01")와 "STEP 01"이 자동으로 붙는다. 번호 없이 **제목과 문구만** 쓰는 형식을 고를 수 있게 한다.
3. **참가 항목 설정 실수를 막는 경고**를 넣는다. 57번 파티에서 "1·2부 통합권"의 포함 회차가 2부만 체크되어 "2부권"과 구성이 같아진 일이 있었다.

**편집하지 않은 파티는 지금과 똑같이 보인다.** 매칭파티 상세는 변경 전과 픽셀 단위로 같아야 한다.

## 3. 참가 신청 방법·필수 확인 사항 편집

### 3-1. 데이터 (`detail`에 추가)

```ts
apply?: {
  title: string;                 // 영역 제목. 기본 "참가 신청 방법" (40자 이하)
  steps: { title: string; desc: string; note: string }[];   // 0~8개. 제목 60자, 설명 500자, 참고 박스 300자
};
notice?: {
  title: string;                 // 영역 제목. 기본 "필수 확인 사항" (40자 이하)
  intro: string;                 // 머리말 (200자 이하)
  items: { title: string; desc: string; warn: string }[];  // 0~10개. 제목 60자, 설명 500자, ⚠ 경고 200자
};
```

- 단계·항목마다 **제목과 설명은 필수**, 참고 박스·경고는 비워도 된다.
- `apply`·`notice`가 **없으면 지금처럼 종류별 기본 문구**(`partyGuides.ts`)로 보여준다. 기존 파티는 데이터 변환 없이 그대로 보인다.
- 단계·항목이 0개로 저장되면 그 영역을 **숨긴다.**
- 서버: `sanitizePartyDetail`에서 위 제한을 검사한다. 글자로만 다루고 HTML로 해석하지 않는다.
- "신청 전 꼭 확인해주세요" 박스는 이번 범위가 아니다. 지금처럼 종류별 고정 문구다.

### 3-2. 기본 문구

- 종류별 템플릿(`templateFor`)에 `apply`·`notice`를 넣는다. 내용은 지금 `partyGuides.ts` 문구 그대로다.
- 솔로파티 기본값의 "신청한 회차 시간 지키기"는, 편집기에 기본값을 채울 때 **그 파티에 참가 구성이 있으면 넣고 없으면 뺀다.** 관리자가 저장한 뒤에는 저장된 그대로 보여준다.
- 화면 모양(번호 동그라미·STEP 글자·참고 박스·⚠ 경고 줄·머리말)은 지금 그대로다.

### 3-3. 관리자 편집기

- 편집기에 두 영역을 추가하고, 상세페이지 순서대로 놓는다: 소개글 → **참가 신청 방법** → 진행 안내 → 소요 시간 → **필수 확인 사항**. 사진 칸 ①~⑤는 지금 자리 그대로 둔다.
- 각 영역 구성
  - 영역 제목
  - 필수 확인 사항만: 머리말
  - 단계·항목 목록: 칸마다 글자 수 표시, 위로/아래로, 삭제, [+ 추가]
  - [기본 문구로 되돌리기] 버튼
- [다른 파티에서 불러오기]로 두 영역도 함께 복사된다.
- 저장 규칙은 지금 상세 안내 저장 방식을 따른다. 편집하지 않은 파티를 그대로 다시 저장해도 화면이 바뀌지 않아야 한다.

## 4. 진행 안내(Party Timeline) 자유 형식

### 4-1. 데이터

- `detail.timeline.numbered: boolean`을 추가한다. 값이 없으면 `true`(지금 모양)로 본다.
- 템플릿 기본값: 매칭파티 `true`, 솔로파티 `false`.

### 4-2. 화면

| `numbered` | 보이는 것 |
|---|---|
| `true` (번호 형식) | 지금과 같다. 번호 동그라미, "STEP 01", 소요 시간, 제목, 설명, 참고 문구 |
| `false` (자유 형식) | **제목과 문구만.** 번호 동그라미·"STEP" 글자·왼쪽 들여쓰기·소요 시간·참고 문구를 그리지 않는다. 문구는 줄바꿈을 살린다. 블록 사이 구분선은 지금처럼 둔다 |

### 4-3. 관리자 편집기

- 진행 안내 영역 위에 **[번호 붙이기] 켜기/끄기**를 둔다.
- 끄면 단계마다 **제목·문구 칸만** 보인다. 소요 시간·참고 문구 칸은 숨기되, 값은 지우지 않는다. 다시 켜면 다시 보인다.
- 자유 형식에서는 **제목과 문구 중 하나만 있어도** 저장된다. 번호 형식은 지금처럼 제목·설명이 모두 필요하다. 서버도 같은 규칙으로 검사한다.

## 5. 참가 항목 설정 실수 경고

- 관리자가 저장할 때 **포함 회차가 똑같은 참가 항목이 2개 이상**이면 확인 창을 띄운다.
  - 문구: "「1·2부 통합권 (BEST)」과 「2부권 (심야 자유교류)」의 포함 회차가 같습니다(2부). 그대로 저장할까요?"
  - [취소]를 누르면 저장하지 않는다. 화면에서만 확인하고, 서버는 막지 않는다.
- 참가 항목 줄마다 포함 회차를 한 줄로 요약해 보여준다(예: "포함: 1부 20:00 · 2부 22:00").
- 신청자가 생기면 포함 회차를 바꿀 수 없다는 안내를 참가 구성 영역 위에 한 줄로 늘 보여준다.

## 6. 변경하지 않는 것 (회귀 금지)

- 편집하지 않은 모든 파티의 상세 화면. 특히 매칭파티는 픽셀 단위로 같아야 한다
- 신청 전 확인 박스(종류별 고정), 소개글, 사진 칸, 소요 시간 표
- 참가 구성·정원·결제·환불·문자·예약 상태 규칙
- 운영 데이터 직접 수정 금지, 배포 보호 규칙
