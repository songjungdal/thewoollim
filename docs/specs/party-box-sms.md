## 1. "신청 전 꼭 확인해주세요" 박스를 파티마다 편집

### 1-1. 데이터 (`detail`에 추가)

```ts
beforeApply?: {
  title: string;   // 박스 제목. 기본 "신청 전 꼭 확인해주세요." (40자 이하)
  body: string;    // 본문 (500자 이하, 줄바꿈 유지)
};
```

- **굵게 표시:** 본문에서 `**글자**`로 감싼 부분만 굵게 보여준다. 그 밖의 기호는 글자 그대로 보이고 HTML로 해석하지 않는다.
- `beforeApply`가 없으면 지금처럼 종류별 기본 문구로 보여준다.
- 기본 문구는 지금 `app/lib/partyGuides.ts`의 굵은 글씨 위치를 `**`로 옮겨 적은 것이다. **편집하지 않은 파티는 화면이 픽셀 단위로 같아야 한다.**
- 본문을 비워 저장하면 박스를 숨긴다.
- 서버: `sanitizePartyDetail`에서 글자 수를 검사한다.

### 1-2. 관리자 편집기

- 상세페이지 안내 편집기 맨 위(소개글보다 위)에 "신청 전 꼭 확인해주세요" 영역을 둔다. 제목·본문 입력칸, 글자 수 표시, [기본 문구로 되돌리기]를 넣는다.
- 본문 칸 아래에 "`**굵게**`처럼 감싸면 굵은 글씨로 보입니다"라고 안내한다.
- 저장 규칙은 `apply`·`notice`와 같다. 기본 문구 그대로면 저장하지 않는다. [다른 파티에서 불러오기]로 함께 복사된다.

## 2. 솔로파티 2시간 전 안내 문자

### 2-1. 범위

- `api/cron/start2h_reminder.php`에서 **솔로파티 예약**만 아래 문구를 쓴다. 매칭파티 문구는 바꾸지 않는다.
- 발송 시점·대상·중복 방지 규칙은 그대로다. 예약마다 처음 참석하는 회차 시작 2시간 전이고, 파티의 현재 회차 시각 기준이다.

### 2-2. 솔로파티 문구

```
[어울림] 파티 시작 2시간 전 최종 안내
안녕하세요, {이름}님!
2시간 뒤 {파티 제목}이 시작됩니다. 즐거운 파티를 위해 아래 안내사항을 꼭 확인해 주세요.
참가: {항목 이름}            ← 참가 구성 예약만 (지금과 같은 줄)
{날짜} {시작 시각}
{장소}

[참석 전 필수 체크사항]
- {입장 시각}부터 입장 가능합니다.
- 늦게 도착하셔도 입장은 가능하지만, 파티가 이미 진행 중이니 가급적 시작 시각 전에 도착해 주세요.
- 입장 시 신분증으로 본인·성인 확인을 합니다. 신분증을 꼭 챙겨 주세요.
- 술과 함께하는 파티이니 차량은 두고 대중교통을 이용해 주세요.
즐거운 파티로 기다리고 있겠습니다. 오시는 길 조심히 오세요!
```

- `{시작 시각}`: 그 예약의 처음 참석 회차 시작 시각(참가 구성이 없으면 파티 시각). 지금 문자와 같다.
- `{입장 시각}`: `{시작 시각}`의 **10분 전**이다. 예: 1부 20:00 → 19:50, 2부만 신청 22:00 → 21:50.
- 90바이트를 넘으므로 지금처럼 장문(LMS)으로 보낸다. 장문 제목은 `[어울림] 솔로파티 시작 2시간 전 안내`.

## 3. 변경하지 않는 것

- 편집하지 않은 파티의 상세 화면(매칭파티 픽셀 비교)
- 매칭파티 2시간 전 문자, 다른 문자 4종, 발송 시점·대상 규칙
- 결제·정원·예약 상태 규칙, 배포 보호 규칙
